-----variables & constent in sh------

A - variables ==> somthing you need it a few times # for example

C1=$(timedatectl)

# instead of re-type this command for HUNDRED TIMES use a simple string to represent this command
# it works with everything :)

B - constent ==> somthing you need it but you dont want it to change it

readonly P1="/home/user/Downloads"

# the readonly will lock the string from changing in the Script
